# Unfold preview level channel

Signed, data-only optional level collections for the Unfold iOS preview. This repository contains no game source code, executable updates, player data or private signing keys.

The native client authenticates catalogs with its bundled public key and verifies payload sizes, SHA256 and installed-physics compatibility. Level files are immutable by pack/revision; the signed catalog uses a monotonically increasing publication sequence. Main campaign progress remains local.

This small preproduction test channel is hosted with GitHub Pages. There are no accounts, analytics, paid transactions or client-side secrets. Hosting-provider request logging follows GitHub policy. Before commercial distribution, reassess hosting terms and delivery capacity.

Level data and names remain the author's intellectual property; publication grants no source-code or asset license.
